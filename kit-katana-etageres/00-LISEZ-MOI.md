# Kit Katana : « Tes étagères font fouillis » (version vert fluo sur noir)

À utiliser dans une session **Claude Cowork** (ou Claude chat) avec le connecteur **Higgsfield** activé.
L'illimité Higgsfield ne marche pas depuis Claude Code : c'est pour ça qu'on passe par Cowork.

## Mode d'emploi
1. Ouvre une session Cowork et glisse **tout ce dossier** dedans.
2. Copie-colle le contenu de `01-PROMPT-A-COLLER.md` comme premier message.
3. Laisse tourner. Katana ne pose pas de questions : il analyse, génère les plans, monte et livre la vidéo.
4. Récupère le MP4. Pour des retouches, dépose-le dans le dépôt `cr-ation-de-contenue`.

## Contenu du dossier
- `01-PROMPT-A-COLLER.md` : le brief complet à coller.
- `02-PLANS-PHRASE-PAR-PHRASE.md` : les 17 plans, un par phrase, avec le moment exact où chacun commence.
- `03-VOIX.md` : le texte de la voix et les réglages ElevenLabs.
- `voix-nicolas.mp3` : la voix prête (Nicolas, ton animateur radio), 37,6 s.
- `logo-em.png` : le logo, en petit sur les 2 dernières secondes.

## Couleur fluo
Le prompt utilise le **vert fluo #39FF14**. Pour l'orange : `#FF5A00`, pour le rouge : `#FF1A1A`.
Remplace le code partout dans le prompt. Une seule couleur fluo par vidéo.
